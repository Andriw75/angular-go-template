Gestion de Archivos

Volver

Sistema de archivos con control de acceso granular por visibilidad.

Niveles de Visibilidad

🌐

Publico

Accesible para cualquier persona sin sesion.

  • Archivos de productos publicos
  • Contenido publico del sitio
Sin restricciones
🔒

Autenticado

Solo usuarios con sesion iniciada.

  • Documentos internos
  • Catalogos privados
Requiere login
👤

Solo Propietario

Solo el usuario que subio el archivo.

  • Documentos personales
  • Borradores no publicados
Solo tu

Flujo de Autenticacion

1
Usuario solicita archivo GET /archivos/{{ '{' }}filename{{ '}' }}
↓
2
Go valida visibilidad + JWT Verifica si el usuario tiene acceso
↓
⇄
X-Accel-Redirect Go devuelve cabecera, nginx sirve el archivo
↓
✔
Archivo servido nginx entrega bytes con sendfile, sin pasar por Go
